🌈 Sarah's Amazing Technicolour Planner

For your privacy — and so it works offline — this planner runs as an installed app on your computer, in its own window, not in a browser tab.

On Mac (Chrome):

  1. Click the install icon in the address bar (or ⋮ menu → "Install Sarah's Amazing Technicolour Planner").
  2. It lands in Applications / Launchpad. For a Desktop icon: open Finder → Applications (or Launchpad), find it, and drag it onto your Desktop or Dock.
  3. Open it from there — own window, works offline.

On Windows (Chrome / Edge):

  1. Click the install icon in the address bar (or ⋮ → "Install").
  2. Tick "Create Desktop shortcut" if asked — it's also in the Start menu.
  3. Open it from the Desktop / Start menu — own window, works offline.

Already installed? Open it from your Desktop / Applications / Start menu instead of this tab.
