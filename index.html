🌈 Sarah's Amazing Technicolour Planner

This planner runs as an installed app on your computer, in its own window. That keeps your work private and lets it open offline. Install it once, then open it from your Desktop.

On Mac (Chrome):

  1. Click the install icon in the address bar, or the ⋮ menu, then "Install Sarah's Amazing Technicolour Planner".
  2. It goes into Applications and Launchpad. For a Desktop icon, open Finder, go to Applications, then drag it onto your Desktop or Dock.
  3. Open it from there. It runs in its own window and works offline.

On Windows (Chrome or Edge):

  1. Click the install icon in the address bar, or the ⋮ menu, then "Install".
  2. Tick "Create Desktop shortcut" if asked. It also appears in the Start menu.
  3. Open it from the Desktop or Start menu. It runs in its own window and works offline.

Already installed? Open it from your Desktop, Applications, or the Start menu instead of this tab.
